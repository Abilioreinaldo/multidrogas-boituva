# MultiDrogas Boituva

Site da farmácia MultiDrogas Boituva, feito pela KnowHowTech.

Acesse: https://abilioreinaldo.github.io/multidrogas-boituva/

## O que tem no site

- **Ofertas da semana** com encartes: Quinta Sênior, Oferta especial e Beleza e banho
- **Cesta** e **reserva para retirada**: o cliente recebe um código e a loja é avisada pelo WhatsApp
- **Minhas reservas**, **lojas**, **receitas** e **serviços**

## Área da loja

Em [`#painel`](https://abilioreinaldo.github.io/multidrogas-boituva/#painel), com login de funcionário:

- Resultados
- Fila de reservas
- Cadastro de ofertas e produtos

## Estrutura

```
index.html   página do site
img/         fotos de produtos, encartes e logo
```

Publicado via GitHub Pages a partir da branch `main`.

> Os dados (cesta, reservas, ofertas e produtos cadastrados) ficam salvos no navegador de quem usa.
