# MultiDrogas Boituva · protótipo

Protótipo navegável de site para a farmácia MultiDrogas Boituva, feito pela KnowHowTech.

- Ofertas da semana (Quinta Sênior, Oferta especial, Beleza e banho) com encartes
- Reserva para retirada com código e aviso no WhatsApp da loja
- Minhas reservas, lojas, receitas e serviços
- Painel da loja (demonstração)

Arquivo único: `index.html` (imagens embutidas). Publicado via GitHub Pages.

> Protótipo: reservas ficam salvas no navegador de quem usa; horários e estoque são ilustrativos.
